# Strawhat Simulator card data

the effect data the rules engine runs and a scenario test for every card.

The simulator is free and will never be monetized. It exists to give players a better way to play.

## What's here

| Path                     | What it holds                                                                                |
| ------------------------ | -------------------------------------------------------------------------------------------- |
| `cards/<SET>.json`       | One entry per card: official stats and text, plus `keywords` and `effects`.                  |
| `images/<card>.png`      | Official card art, downloaded from the official card list.                                   |
| `scenarios/<SET>/`       | Scenario tests. Each file starts with the card number it tests.                              |
| `STATUS.md`              | Every card and whether it is tested. Generated by `pnpm status`.                             |
| `formats/<id>.json`      | Deck-building rules for a format (Standard): legal blocks, banned, restricted, banned pairs. |
| `decks/<STxx>.json`      | Official starter deck lists: `leader` plus 50 `cards` as card number → copies, and `source`. |
| `engine.json`            | The engine commit the scenarios run against.                                                 |
| `test/helper-cards.json` | Made-up `TEST-` cards used as opponents and fillers in scenarios.                            |

## Running the tests

```sh
pnpm install
pnpm check
```

`pnpm test` first downloads the engine at the commit in `engine.json` into `.engine/`.

## Hand-written fields

Re-running the importer keeps `keywords`, `effects`, and `aliases`. `aliases` lists other names a
card counts as ("Also treat this card's name as [Tony Tony.Chopper] according to the rules").
